# Changelog

## 5.0.0

- Add official **ESLint 8** support (`peerDependencies.eslint`: `^7.0.0 || ^8.0.0`).
- Remove bundled `typescript` dependency (consumers already provide TypeScript).
- Bump `@typescript-eslint/parser` and `eslint-config-prettier` dependency ranges.

No rule changes from 4.x — safe to upgrade from `4.0.10` on ESLint 7 or 8.
